Preguntas frecuentes

Lo que suelen preguntarnos

¿Para qué negocios trabajáis?

Para autónomos, pymes y empresas de cualquier sector y lugar: estamos en A Coruña, pero trabajamos a distancia con toda España y fuera. Adaptamos la web y el sistema de captación, reservas o cualificación a cada negocio.

¿Qué incluye un sistema y cuánto cuesta?

Cada sistema cuesta 1.000 € e incluye una web rápida orientada a llamadas y WhatsApp, el alta de la base de datos (pacientes, vehículos o leads, según el sector), la configuración de plantillas de recordatorio por WhatsApp (un botón abre WhatsApp con el texto escrito; los envíos programados solo si se montan en la puesta en marcha, y se acuerda antes) y la importación de los registros que ya tienes en tu programa de facturación. Si un trabajo tiene un alcance distinto, lo presupuestamos antes.

¿Tenéis una web más sencilla?

Sí. Una web clara para tu negocio cuesta 350 €, en un único pago. El hosting y el dominio están incluidos el primer año; el dominio se renueva después al precio del registrador. El mantenimiento es opcional y se presupuesta aparte.
